# Beta test information

## Beta app description

Hotel Dusk: Room 215 is an experimental native adaptation with a book-style interface.
Explore the hotel, read conversations, inspect items, solve puzzles, and use Kyle's notebook.
This beta focuses on touch controls, save and resume, audio, and the folding display on Duo.

The adaptation is incomplete. Some story branches, visual details, audio cues, and puzzle behaviour still need verification.
Progress through automated checkpoints does not prove that every chapter works in one uninterrupted session.

## What to test

Start with **Begin Chapter 1**. Check the lobby, front desk, bell, registration, conversations, and notebook.

- Check that Continue restores your place after quitting or backgrounding.
- Check item selection, puzzle gestures, page turns, and notebook writing.
- Switch between Native music and Recorded soundtrack.
- Check both microphone input and the touch alternative where available.
- On Duo, fold and reopen the device during play.
- Look for blurred animation details, transparent edges, clipped text, and misplaced touch targets.

If play stops, try **Book options → Pause game → Return to last safe place**.
You may need to repeat the current interaction.

Send feedback through TestFlight. Include the chapter, room, last action, device, system version, and app build number.
Include a screenshot when it helps explain the problem.

## Beta review notes

No account or login is required. The game resources are included for offline play.
The beta uses a 4× animation pack to reduce its download and installation size.
Microphone permission is optional. The relevant puzzles also provide touch input.
Development previews are absent from Release builds.

Select **Begin Chapter 1** to start. At the front desk, face the counter and select **Inspect**.
Use the slider to look across the counter, then tap the bell three times.
